# xfks-auto-next（学法考试自动翻页）

给「广东省国家工作人员学法考试平台」课程页写的油猴脚本：课程内容需要逐页学习，每页右下角有一个积分徽标（如 **0.5分**），**徽标变蓝表示本页积分已发、允许翻页**。本脚本自动监控徽标颜色，**变蓝即自动点击右侧翻页箭头**，无需人工盯守。

> 仅供个人学习辅助使用，请自行遵守平台相关规定。

## 功能

- 🔵 监控右下角积分徽标（`0.5分` / `1分` 等），变蓝后自动点击右侧翻页箭头
- 🛡️ 只点右半屏的箭头，排除「上一页 / 左箭头 / 禁用态」，不会点回去
- 🖥️ 右下角悬浮窗：实时显示徽标状态（蓝/灰）、翻页次数、最近点击时间
- ⏸️ 悬浮窗可暂停/继续，面板可拖动；点击后 5 秒冷却防连点
- 🔄 页面刷新/翻页后脚本自动重新生效（油猴托管）

## 安装

### 方式一：Tampermonkey 一键安装（推荐）

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展
2. 打开（仓库设为 Public 后可直接点）：
   `https://raw.githubusercontent.com/arkchan/xfks-auto-next/main/xfks-auto-next.user.js`
   Tampermonkey 会自动弹出安装页，点「安装」即可
3. 若仓库是 Private，先在本机克隆后手动粘贴（见方式二）

### 方式二：手动粘贴

1. 安装 Tampermonkey → 点扩展图标 → 「添加新脚本」
2. 清空模板，粘贴 `xfks-auto-next.user.js` 全部内容，`Ctrl+S` 保存
3. 打开课程页（如 `/study/course/12812`），右下角出现「xfks 自动翻页」悬浮窗即生效

> 临时试用：课程页按 `F12`，把整个脚本粘到 Console 回车（页面刷新后失效）。

## 工作原理

```
每 800ms 一轮：
  1. 找积分徽标：文字匹配 / 0.5分 | 1分 / 的最小可见元素
  2. 徽标变蓝？  背景色/文字色蓝通道明显占优，或类名含 blue/active/done
  3. 变蓝 → 找翻页目标：右侧半屏的箭头(类名 next/arrow/chevron、文本 > ›)
     或文字「下一页」按钮，排除 prev/left、大容器、禁用态
  4. 模拟 mousedown/mouseup/click 点击 → 冷却 5 秒
```

## 配置

编辑脚本开头 `CFG`：

| 参数 | 默认 | 说明 |
|---|---|---|
| `interval` | `800` | 检查间隔（毫秒） |
| `cooldown` | `5000` | 点击后冷却（毫秒），防连点 |
| `scorePattern` | `/^\d+(\.\d+)?\s*分$/` | 积分徽标的文字格式 |
| `requireBadge` | `true` | 必须徽标变蓝才点；改 `false` 则跳过颜色检查 |
| `fallbackTextNext` | `true` | 无徽标的页面退回「下一页」文字按钮检测 |
| `showPanel` | `true` | 是否显示悬浮窗 |

## 常见问题

- **一直显示「灰色，等待积分」不翻页**：正常，每页需满学习时长（约 1 分钟）积分才变蓝，脚本会在变蓝瞬间自动点击。
- **徽标变蓝但没点**：F12 控制台看 `[自动翻页]` 日志；把翻页箭头的 HTML（右键箭头 → 检查）发 Issue，我帮你把选择器写死。
- **挂着时页面别切到后台**：Chrome 会把后台标签页的定时器节流到每分钟 1 次，建议窗口保持可见或单独开小窗。
- **误点**：把 `cooldown` 调大，或参考上一条反馈箭头的真实类名。
